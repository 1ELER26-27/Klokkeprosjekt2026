# `visKlokkevisere`

**Laget av:** Johan og Aleksander

**Hva gjør den?**
den viser klokkevisere på ledlysene. sekund viser, minutt viser, og timeviser.

**Parametere:**

time og minutt er parametere.

**Returverdi:**

return sek_pix % NUM_LEDS; 
return min_pix % NUM_LEDS;
return time_pix % NUM_LEDS;

**Refleksjon:**
fordi det fungerer derfor gjorde vi det sån. den første fungsjonen din fungerte ikke så vi fikset denn og skrev litt mer under. og viste funksjonene med show og litt sånt.
